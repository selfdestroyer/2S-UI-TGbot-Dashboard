# Роадмап: перенос нового дашборда подписки

Задача: заменить текущий `index.html` на новую страницу из макета. Логика бэкенда не меняется: страница по-прежнему получает данные из `/api/subscription/{имя}`, а `app.py` подставляет в неё настройки из `.env`.

Новый файл: `index.html`. Он самодостаточный, без внешних скриптов. Внутрь встроена библиотека QR-кодов [qrcode-generator](https://github.com/kazuhikoarase/qrcode-generator) (MIT), снаружи грузятся только шрифты Google Fonts.

## Этап 2. Импорт в Throne вместо копирования

На старой странице кнопка Throne только копировала ссылку и просила нажать Ctrl+V (функция `copyForThrone()`). На новой странице главная кнопка открывает Throne и сразу предлагает добавить подписку.

**Как это устроено.** Throne понимает ссылки вида:

```
throne://addsub/<base64 от строки "ССЫЛКА_НА_ПОДПИСКУ#НАЗВАНИЕ">
```

Throne декодирует base64, берёт адрес подписки и название из части после `#`. Затем показывает окно «Add this subscription?» с галочкой автообновления. Это видно в исходниках Throne: `src/ui/mainWindow/mainwindow_deeplink.cpp`, функции `handle_deeplink_impl` и `handle_addsub`.

На странице ссылку собирает функция `APPS.throne.deeplink`:

```js
'throne://addsub/' + b64utf8(subUrl + '#' + encodeURIComponent(projectName))
```

Base64 обычный, не URL-safe: Throne декодирует его через `QByteArray::fromBase64Encoding` со стандартными опциями. Название кодируется в UTF-8, поэтому кириллица в `PROJECT_NAME` работает.

**Если приложение не открылось.** Через 2,2 секунды после нажатия страница проверяет, ушёл ли пользователь в приложение. Если окно браузера всё ещё активно, появляется подсказка «Приложение не открылось?». Кнопка «Копировать» рядом с полем ссылки осталась, так что старый способ через Ctrl+V тоже работает.

**Проверка вручную до выкладки.** Собрать ссылку и открыть её в системе:

```bash
# Linux
LINK="throne://addsub/$(printf '%s' 'https://ДОМЕН:2096/sub/ИМЯ#Podnyatie' | base64 -w0)"
xdg-open "$LINK"

# macOS
open "throne://addsub/$(printf '%s' 'https://ДОМЕН:2096/sub/ИМЯ#Podnyatie' | base64)"
```

```powershell
# Windows (PowerShell)
$b = [Convert]::ToBase64String([Text.Encoding]::UTF8.GetBytes('https://ДОМЕН:2096/sub/ИМЯ#Podnyatie'))
Start-Process "throne://addsub/$b"
```

- [ ] Throne открылся и показал окно «Add this subscription?» с правильным адресом и названием.
- [ ] После подтверждения подписка появилась в списке, серверы загрузились.

Ссылки Hiddify (`hiddify://import/…`) и Incy (`incy://add/…`) остались такими же, как на старой странице.

## Этап 5. Доработки `app.py` (желательно)

Страница работает и без них, но эти правки закрывают известные проблемы.

- [x] **Экранировать `PROJECT_NAME` в JS.** Сейчас `app.py` вставляет название в `window.PROJECT_NAME = "…";` как есть, и кавычка в названии ломает весь скрипт. Решение: подставлять через `json.dumps(project_name, ensure_ascii=False)` вместо `"{project_name}"`. То же для остальных четырёх переменных.
- [x] **Передавать путь подписок из панели.** `install.sh` уже читает `subPath` из настроек 2S-UI (`PANEL_SUB_PATH`), а страница по умолчанию считает, что путь `/sub`. В новой странице есть строка `window.PANEL_SUB_URL = window.PANEL_SUB_URL || "";`. Достаточно добавить в `.env` переменную `PANEL_SUB_URL=https://ДОМЕН:ПОРТ/путь` и ещё одну замену в `get_html_content()`:
  ```python
  panel_sub_url = os.getenv("PANEL_SUB_URL", "").strip()
  content = re.sub(r'window\.PANEL_SUB_URL\s*=\s*[^;]+;', f'window.PANEL_SUB_URL = {json.dumps(panel_sub_url)};', content)
  ```
- [x] **Заголовок кэша API.** Заменить `Cache-Control: public, max-age=3600` на `private, max-age=300`. Это персональные данные, а страница и так кэширует их в браузере на час.
- [x] **Миллисекунды в датах.** Бот уже понимает `expiry` и `next_reset` в миллисекундах, а `app.py` нет. Страница сама приводит оба формата к секундам, но поля `days_left` и `is_expired` считает `app.py`, и при миллисекундах они будут неверными. Стоит вынести в `app.py` такую же функцию `normalize_ts()`, как в боте.
