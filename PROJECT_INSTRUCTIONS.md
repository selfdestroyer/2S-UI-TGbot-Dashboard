## 1. Общее описание и архитектура

**2S-UI-TGbot-Dashboard** — это готовый к развертыванию программный комплекс, объединяющий:
1. **Telegram-бота на Aiogram 3:** автоматизирует выбор тарифов, приём чеков, проверку подписок, напоминания об окончании и сервисные рассылки с TTL.
2. **Веб-дашборд на FastAPI:** микросервис валидации клиентов и современный адаптивный лендинг с кнопками быстрого подключения (Hiddify, Incy, Happ, Streisand, v2rayN и др.).

### Схема взаимодействия компонентов:

```text
                           [ Пользователь / Клиент ]
                                  │          │
                 (Веб-интерфейс / │          │ (Telegram Bot)
                  Импорт конфига) │          │
                                  ▼          ▼
                      ┌───────────────────────────┐
                      │    Nginx Reverse Proxy    │
                      │         (Порт 443)        │
                      └───────┬───────────┬───────┘
          / (Веб-дашборд)     │           │  /sub/ (Сырые конфиги)
                              ▼           ▼
                   ┌─────────────────┐ ┌─────────────────┐
                   │  vpn-dashboard  │ │  2S-UI / X-UI   │
                   │ (FastAPI: 8000) │ │  (Порт 2096)    │
                   └────────┬────────┘ └────────┬────────┘
                            │                   │
                            │  Чтение SQLite    │
                            ▼                   ▼
    ┌─────────────────────────────────────────────────────────────┐
    │          База данных панели (/usr/local/s-ui/db/s-ui.db)     │
    └─────────────────────────────▲───────────────────────────────┘
                                  │
                                  │ Чтение клиентов
                                  │
                      ┌───────────┴───────────┐
                      │        vpn-bot        │
                      │  (Telegram Aiogram 3) │
                      └───────────────────────┘
```

## 4. Интеграция с базой данных 2S-UI и полуавтоматический режим

### Прямой доступ к базе SQLite (без API)
* Бот и веб-сервер **не используют HTTP / REST API** панели 2S-UI, а обращаются напрямую к SQLite файлу базы данных `s-ui.db`.
* Это исключает проблемы с авторизацией, куками сессий, сменой портов веб-интерфейса панели и обеспечивает максимальное быстродействие.

### Структура таблицы `clients` в базе панели:
* `id` (`INTEGER`) — внутренний ID клиента в панели.
* `name` (`TEXT`) — системное имя клиента (slug в URL: `https://sub.domain/{name}`).
* `desc` / `remark` (`TEXT`) — поле описания, в которое **вносится Telegram ID** пользователя.
* `expiry` (`INTEGER`) — время окончания подписки в Unix-timestamp (0 — бессрочно).
* `enable` (`INTEGER`) — признак активности клиента (1 — активен, 0 — заблокирован).
* `volume` (`INTEGER`) — лимит трафика в байтах (0 — безлимит).
* `down` / `up` (`INTEGER`) — количество скачанных и переданных байт.

### Регламент добавления клиентов (Полуавтоматический режим):
1. Клиент выбирает тариф в боте и отправляет скриншот чека.
2. Администратор получает заявку в Telegram с фото, суммой и **цифровым Telegram ID клиента**.
3. Администратор нажимает `[ ✅ Одобрить ]`, переходит в панель управления 2S-UI и создает клиента (или продлевает существующего).
4. ⚠️ **ОБЯЗАТЕЛЬНОЕ УСЛОВИЕ:** В панели в поле **`Description`** (в некоторых версиях `Remark`) администратор **вручную указывает Telegram ID клиента** (например, `123456789`).
5. Как только клиент сохранен в панели, бот сразу находит его в базе и открывает доступ к подписке.

## 5. Разделение ссылок и маршрутизация (Дашборд vs Панель)

В проекте строго разграничены две разные ссылки:

1. **Ссылка от Telegram-бота на веб-дашборд:**
   * Формат: `https://{SUB_DOMAIN}/{client_name}` *(например: `https://sub.example.com/ivan`)*.
   * Выдается клиенту в боте по кнопке «🔑 Моя подписка».
   * Открывается в любом мобильном или десктопном браузере.

2. **Ссылка на подписку для VPN-приложений (из панели):**
   * Формат: `https://{MAIN_DOMAIN}:{PANEL_PORT}/sub/{client_name}` *(например: `https://example.com:2096/sub/ivan`)*.
   * Размещена внутри веб-дашборда в поле «Ссылка на подписку» и привязана к кнопкам прямого импорта (Hiddify, Incy, Happ, Streisand, v2rayN).

## 6. Служебная база данных бота (bot_data.db)

Для внутренних задач бот использует отдельный SQLite файл `bot_data.db`:

1. **`notification_history`**:
   * Хранит записи об отправленных напоминаниях (`client_name`, `threshold_type`, `expiry_timestamp`, `sent_at`).
   * Защищает от дублирования сообщений при перезапусках бота.
2. **`scheduled_deletions`**:
   * Очередь сообщений рассылки с таймером автоудаления (`chat_id`, `message_id`, `delete_at`).
   * Фоновый воркер проверяет таблицу каждые 30 секунд и удаляет сообщения из чатов через API Telegram.

## 7. Пользовательский функционал Telegram-бота

### Главное меню
* Доступно по команде `/start` или кнопке «◀️ Главное меню».
* Информационное приветствие с названием сервиса, правилами и кнопками:
  * «💳 Купить / Продлить»
  * «📦 Ваша подписка»
  * «💬 Поддержка»
  * «⚙️ Сервисное меню» (отображается только администратору)

### Личный кабинет «Ваша подписка»
* Бот ищет подписки по Telegram ID пользователя в таблице `clients` панели 2S-UI.
* Если подписка найдена: выводятся инлайн-кнопки со ссылками на веб-дашборд вида `{Имя} | {Срок}`.
* Если подписка не найдена: выводится инструкция по покупке и контакт саппорта.

### Оформление покупки и модерация чеков
* Клиент выбирает период (1, 3, 6, 12 месяцев).
* Бот переводит FSM в состояние ожидания чека (`BuySubscriptionState.waiting_for_receipt`), выводит реквизиты.
* После загрузки чека администратор получает карточку заявки с кнопками `[ ✅ Одобрить ]` и `[ ❌ Отклонить ]`.

## 8. Автоматические напоминания и фоновые демоны

### Фоновый воркер уведомлений
Корутина `notification_worker` запускается раз в час и отслеживает даты окончания подписок:
* **За 7 дней:** мягкое напоминание о скором завершении срока.
* **За 3 дня:** предупреждение о необходимости продления.
* **За 12 часов:** срочное уведомление.
* **В момент истечения:** уведомление об отключении с кнопкой продления.

### Умная рассылка с автоудалением по таймеру (TTL)
* Доступна в меню `/admin`.
* Поддерживает форматированный текст, фото и инлайн-кнопки со ссылками.
* Выбор времени жизни (TTL): 15 минут, 1 час, 12 часов, 24 часа, произвольный интервал или бессрочно.
* Сообщения автоматически удаляются из чатов всех клиентов по истечении таймера, не захламляя переписку.

## 9. Веб-дашборд и валидация подписок (app.py & index.html)

Микросервис FastAPI (`app.py`):
1. **API эндпоинт:** `GET /api/subscription/{username}`
   * Возвращает JSON со статистикой клиента: активность, срок действия, дни до окончания, использованный и оставшийся трафик.
   * Ответ кэшируется на 1 час (`Cache-Control: public, max-age=3600`).
2. **Фронтенд эндпоинт:** `GET /{sub_path}`
   * Проверяет существование клиента в базе `s-ui.db`.
   * Если клиент существует — отдает интерфейс `index.html`.
   * Если клиент не найден — отдает информативную страницу 404 со ссылкой на Telegram-бота.
3. **Фронтенд `index.html`:**
   * Адаптивный дизайн (Mobile-first, Dark Theme).
   * Круговой индикатор трафика и срока подписки.
   * Кнопки импорта в один клик: `hiddify://import/...`, `incy://add/...`.
   * Копирование ссылки на подписку в буфер обмена для v2rayN, Happ, Streisand.

## 10. Автоматическая установка и обновление (install.sh & update.sh)

### Автоматическая установка `install.sh`:
```bash
git clone https://github.com/selfdestroyer/2S-UI-TGbot-Dashboard.git /root/2S-UI-TGbot-Dashboard
cd /root/2S-UI-TGbot-Dashboard
sudo bash install.sh
```

Что делает скрипт:
1. Проверяет права `root`, ОС (Ubuntu/Debian) и базу панели `s-ui.db`.
2. Интерактивно запрашивает параметры: основной домен панели, поддомен дашборда, токен бота, ID админа.
3. Устанавливает системные пакеты (`nginx`, `python3-venv`, `certbot`, `python3-certbot-nginx` и др.).
4. Копирует проект в рабочую папку `/var/www/2S-UI-TGbot-Dashboard`.
5. Создает единое виртуальное окружение `venv` и ставит библиотеки из `requirements.txt`.
6. Генерирует защищенный `.env` (`chmod 600`) и настраивает фронтенд `index.html`.
7. Конфигурирует виртуальный хост Nginx и выпускает бесплатный SSL Let's Encrypt через Certbot.
8. Регистрирует, активирует и запускает службы `vpn-bot` и `vpn-dashboard`.

### Быстрое обновление `update.sh`:
```bash
cd /root/2S-UI-TGbot-Dashboard
sudo bash update.sh
```
Подтягивает изменения из Git, обновляет pip-зависимости и перезапускает службы без простоя и без сброса баз данных и файлов `.env`.

## 11. Управление системными службами (Systemd)

Оба сервиса функционируют независимо в папке `/var/www/2S-UI-TGbot-Dashboard`:

```bash
# Статус служб
systemctl status vpn-bot
systemctl status vpn-dashboard
systemctl status nginx

# Просмотр логов в реальном времени
journalctl -u vpn-bot -f
journalctl -u vpn-dashboard -f

# Перезапуск служб
systemctl restart vpn-bot
systemctl restart vpn-dashboard

# Изменение настроек (.env)
nano /var/www/2S-UI-TGbot-Dashboard/.env
systemctl restart vpn-bot vpn-dashboard
```

## 12. Безопасность

* Файлы `.env`, базы SQLite (`*.db`, `bot_data.db`), виртуальные окружения и кэш исключены в `.gitignore`.
* Внешний веб-интерфейс работает исключительно в режиме чтения базы данных.
* Настройки доступа к файлу конфигурации на сервере ограничены правами суперпользователя (`chmod 600`).
* Прямой доступ к конфигурациям панели защищен SSL-сертификатом Let's Encrypt.
